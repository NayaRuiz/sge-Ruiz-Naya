# UT3 – Organización y consulta en Odoo

En esta unidad se configura InfoTaller en Odoo, se gestionan usuarios y permisos, se crean grupos y menús personalizados, se importan y actualizan datos maestros y se realizan los circuitos de venta, compra y reabastecimiento.

## Índice de actividades

- [UT3.1 – Puesta en marcha de InfoTaller](UT3.1-puesta-en-marcha/README.md)
- [UT3.2 – Un grupo y un menú a medida](UT3.2-grupo-menu/README.md)
- [UT3.3 – Cargamos los datos maestros](UT3.3-datos-maestros/README.md)
- [UT3.4 – InfoTaller vende y compra](UT3.4-circuitos/README.md)

## Herramientas

- Ubuntu Server 24.04 LTS como servidor de Odoo (según la instalación de la UT2).
- Odoo 18.
- Hojas de cálculo XLSX para importar, exportar y actualizar datos.
- Git y GitHub para documentar y entregar las actividades.
